# Daisys by Liv

Website and planning board for Daisys, environmental and skin friendly care by Liv Breidenthal.

| Folder | What it is |
|---|---|
| `site/` | The public coming soon page for daisysbyliv.com |
| `board/` | The four Ps scrum board for Liv (runs as a claude.ai artifact, not on the public site) |
| `docs/` | Notes, including how to publish |

## Branches

| Branch | Purpose |
|---|---|
| `main` | Snapshot of what was first built. The sign-up box here uses claude.ai storage, so it does not work on a normal website. |
| `publish` | The version to put on daisysbyliv.com, with a working sign-up form and publishing steps. |
| `board-improvements` | Better scrum board: priorities, moves, editing and AI tips. |
